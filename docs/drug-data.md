# 药物数据约定

## v4.3 题库与来源

v4.3 共收录 **232 种**考研核心代表药物，完整保留 `01`～`210` 历史编号并顺延新增 `211`～`232`，按药理体系划分为 **24 个纯粹独立的药理大类**，并为每条药物定义无“其他类”的具体化学结构/药理亚类（`subcategory`）、权威作用靶点与机制（`mechanism`）及连续教材顺序序号（`sortOrder` `1`～`232`），确保同一大类内同小类药物严格连续排列。

结构数据逐项读取 PubChem PUG REST 的 CID、Isomeric SMILES、Connectivity SMILES、MolecularFormula、Charge、IUPACName 与 Synonyms 接口。中文品名逐项检索政府公开的《中国药典》2025 年版二部品名目录与《国家基本药物目录（2018 年版）》；命中页码、作用机制和立体说明保存在 `tools/drug_reference.json`。

## 数据字段与校验

| 字段 | 说明 |
| --- | --- |
| `id` | `01`～`232` 固定编号（升级永不变更，确保覆盖安装无损保留历史进度、错题本与已屏蔽列表） |
| `smiles` | PubChem 选定活性分子形态的异构 SMILES（顺式外消旋体含 CXSMILES AND 组，顺铂含平面四配位顺式构型） |
| `structure` | `assets/structures/{id}.svg`，0° 资源路径 |
| `chapter` | 24 个标准药理大类之一 |
| `subcategory` | 大类下的具体化学结构/药理亚类（禁止出现“其他”等笼统归类） |
| `mechanism` | 权威核对的作用靶点与作用机制 |
| `category` | 统一展示标签，固定为 `chapter · subcategory` |
| `sortOrder` | `1`～`232` 教材连续排列序号（顺序模式据此排序，确保同亚类严格连续） |
| `aliases` | 中文习惯名、临床无机盐型名、英文 INN 与检索别称 |
