# 需求说明

## 产品目标

帮助药物化学考研与专业学习者建立药物结构式、中文通用名、具体化学结构亚类及作用靶点机制的多维对应关系，通过看图回忆、分章节与亚类刷题、手动屏蔽过滤不考条目、四选一模拟测验、拟真考场防背图旋转、错题本攻坚与离线反查结构辅助高效备考。

## 平台与题库（v4.3）

- 采用 Dart + Flutter，交付可完全离线运行的 Android APK（应用名称：`要学结构式`）。
- 题库收录 **232 种**考研核心代表药物，完整保留 `01`～`210` 历史编号并顺延新增 `211`～`232`，按药理体系划分为 **24 个纯粹独立的药理大类**，为每条药物定义**无“其他类”的具体化学结构/药理亚类（`subcategory`）**、**权威作用靶点与机制（`mechanism`）** 及连续教材排序序号（`sortOrder` `1`～`232`），确保同一大类内同亚类药物严格连续排列：
  1. 镇静催眠药与抗癫痫药（13）
  2. 抗精神病药（8）
  3. 抗抑郁药（4）
  4. 镇痛药（8）
  5. 神经退行性疾病、麻醉与中枢兴奋药（12）
  6. 拟胆碱、抗胆碱与拟肾上腺素药（12）
  7. 抗过敏药（6）
  8. 抗高血压药（15）
  9. 利尿药（4）
  10. 抗心律失常与抗心绞痛药（5）
  11. 调血脂药（7）
  12. 抗凝血与抗血小板药（2）
  13. 消化系统药物（14）
  14. 解热镇痛、非甾体抗炎及抗痛风药（18）
  15. 抗肿瘤药（18）
  16. 抗生素（23）
  17. 合成抗菌药（12）
  18. 抗结核药（4）
  19. 抗真菌药（5）
  20. 抗病毒药（8）

- **第一原则（准确与可靠）**：全部 232 种药物均通过权威化学数据库（PubChem / WHO INN / IUPHAR-BPS）、人卫版《药物化学》与《中国药典》2025 版二部品名目录/国家基本药物目录交叉核对，经 Python 3.11 + RDKit 校验具体亚类规范性、作用机制完整性、分子式、连接与立体唯一性、电荷及手性/顺反构型，确保 100% 准确。
- **拟真考场防背图四向矢量资源**：除标准 `0°` 结构图外，通过 RDKit 刚体旋转 2D 原子坐标并重新生成正立原子标签与对应楔/虚键，输出 `90° / 180° / 270°` 三个无倒字旋转变体（共 `232 × 4 = 928` 张 480×280 透明底 SVG），全部通过 MolBlock 往返立体构型校验（含顺铂平面四配位顺式配合物与西沙必利/酮康唑/伊曲康唑顺式外消旋体），杜绝改变构型的镜像翻转。

## 核心功能流程

### 底部四 Tab 导航与独立屏蔽管理页

底部保持「复习」「测验」「错题本（带未屏蔽待攻克数量角标）」「查结构」四个标签页，使用 `IndexedStack` 保持状态，全局共享难点集合、已屏蔽集合、拟真考场旋转开关与护眼主题；通过复习控制条及测验配置页的「已屏蔽 (N)」入口打开独立的 **「已屏蔽结构式」专属管理页**。

### 结构式复习与手动屏蔽

1. 顶部汇总卡片展示学科微标、当前未屏蔽范围核对进度条、上次停留定位条、护眼主题按钮与带确认弹窗的重置按钮。
2. 药理大类筛选横向胶囊栏 + 「按药理大类筛选」底部总览面板；选中包含多个亚类的大类后，展开一行**具体化学/药理亚类筛选胶囊**，支持直达某一亚类精准刷题。
3. 顺序 / 乱序分段开关、洗牌按钮、**「考场旋转」** 切换胶囊与 **「已屏蔽 (N)」** 管理入口；顺序模式按 `sortOrder` 排列保证同亚类连续出现。
4. 盲测态严格隐藏药名、分类与靶点机制；揭晓后完整展示 **药理大类 + 具体亚类 + 作用靶点与机制** 三层考点；卡片顶栏支持一键 **「屏蔽」**（立即隐藏并弹出带撤销的操作提示条）与 **「标难 / 难点」** 星标。

### 互动四选一测验（联动过滤已屏蔽条目）

1. **配置页**：支持三类题型（「看图选名」「看名选图」「混合题型」）、三类出题范围（全部可测 / 按药理分类：24 大类总览秒选 + 二级亚类细选 / 错题本专项）、题量（10/20/30/全部）、「拟真考场旋转」开关以及「已屏蔽 (N)」快捷管理条。
2. **自动过滤与同族高迷惑干扰项**：已屏蔽药物绝不作为被考题目出现，干扰项优先从**未屏蔽**的同二级亚类、同药理大类与全库中抽取。
3. **沉浸答题与交卷复盘**：作答后即刻给出正误反馈、具体结构亚类与作用靶点机制，**答错自动加入错题本**；交卷复盘页展示成绩、用时与错题明细（含靶点机制解析），支持重练本轮错题与错题专项批量移出。

### 错题本、离线查结构与已屏蔽结构式管理

- **错题本**：集中复习未屏蔽的难点药物，支持大类 + 亚类筛选、顺序/乱序、考场旋转、盲测回忆揭晓三层考点及一键「已掌握，移出错题本」（带撤销）。
- **查结构**：支持按编号、中文通用名、别称/英文名、药理大类、具体结构亚类与**作用靶点/机制**多字段离线检索，支持一键标难与切换屏蔽状态。
- **已屏蔽结构式管理页**：集中展示用户手动屏蔽的结构式卡片，支持大类/亚类筛选、关键词检索、单条一键「恢复学习」（带撤销）及右上角一键「全部恢复」。

### 深色护眼、专属考研鼓励与无损覆盖升级

- 支持「跟随系统 / 日间蓝图 / 深色护眼」三态切换并持久化，深色模式自动将 SVG 着色为月光白 `#E6EEF8`。
- 保留面向「赵总赵欣怡」定制的每日首次时段感知鼓励大卡片、二次打开轻提示与退出告别学习小账单。
- **覆盖安装无损保留数据**：沿用包名 `com.medchem.review.drug_structure_review` 与 `shared_preferences` 键名（`review_progress_v2`、`study_preferences_v3`），新增 `excludedIds` 采用字段级独立解析与空集回退，升级安装后完整保留历史进度、错题本、主题偏好与测验成绩。
